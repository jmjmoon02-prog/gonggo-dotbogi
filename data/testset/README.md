# 테스트셋 (`testset.yaml`)

검증 노트북(`notebooks/eval.ipynb`)이 쓰는 가상 공고 53건입니다.

## 구성
| 구분 | 그룹 | 건수 |
|---|---|---|
| 사기 시나리오 11종 | G1~G7, G12~G15 (공식 자료로 확인한 수법 유형, 그룹별 근거 ID는 `testset.yaml` `meta.groups`, 근거 URL은 `rules/rules.yaml` `evidence`) | 11 × 3 = 33 |
| 정상 공고 5종 | N1 정식 플랫폼 / N2 사업자번호 없는 정상 / N3 소상공인 SNS 모집 / N4 '고수익' 정상 영업직 / N5 정상 판매·택배 위탁직 | 5 × 4 = 20 |

## 라벨 기준
- `expected_grade`: 판정 규칙 v2를 사람이 적용했을 때의 기대 등급.
- `acceptable_grades`: 허용 등급. 예를 들어 사칭과 선입금이 함께 나오면 🔴, 🟠 둘 다 허용합니다.
- `expected_rules`: 걸려야 하는 규칙 ID. 그룹별 근거 ID는 `meta.groups`에 있습니다.
- 정상 공고 가운데 비공식 경로(커뮤니티·SNS)로 받은 것은 신뢰 신호가 없어서 최고 등급이 ⚪ 확인 필요입니다(규칙 v2).

## 지표 정의 (eval.ipynb)
- **탐지율(사기):** 예측 등급이 🔴·🟠·🟡 중 하나인 비율. 예측 등급이 `acceptable_grades` 안에 드는 비율(엄격 일치)도 함께 보고합니다.
- **오탐률(정상):** 예측 등급이 🔴·🟠·🟡 중 하나인 비율. 정상 클래스(N1~N5)별로 따로 보고합니다.
- **신종 탐지율('유형 하나 빼기'):** 그룹 X 전용 규칙을 뺀 규칙으로 X 시나리오를 다시 판정했을 때 🔴·🟠·🟡로 잡히는 비율. 추출 결과를 재사용하므로 추가 API 비용이 없습니다.
- **인용 검증 통과율:** AI가 낸 근거 문장 가운데 마스킹된 원문에서 확인된 비율.

## 출처와 한계
- 문장 전체는 Claude(AI)로 작성한 **가상 시나리오**입니다. 실제 개인정보와 실존 업체는 없습니다. 업체명에는 '가상' 접두어를 붙이고, 브랜드명은 일반화했습니다.
- 실제 사기 공고를 모은 데이터가 아니어서 **합성 편향**이 있을 수 있습니다. 규칙을 만든 쪽과 테스트셋을 만든 쪽이 같다는 순환 위험도 있습니다. 사람 검토는 아직 하지 않았습니다.
- 이 자료는 AI 활용내역에 기재해야 합니다.
